# M16: アイテムごとのクリック範囲

対象: feature/m16-item-hotspots。M15背景指定・入力修正から継続。シーンのセットアップメニュー再実行は不要。

## 変更

従来のCloseup内2ボタンを引き続き使い、表示中のItemDefinitionに合わせて範囲を切り替える。6個別々に設定できる。Use Custom HotspotがOFFなら実行開始後に記憶した元のシーン配置を復元する。未設定の別家具へカスタム位置を持ち越さない。取得済みの非表示、家具完了、4個目の優先、ホバーの有効/無効は既存処理を維持する。

## 設定方法

Play停止中にAssets/Data/Definitions/ITEM_01.asset〜ITEM_06.assetを選び、Exploration click areaのUse Custom HotspotをONにする。Hotspot RectはX / Y / Width / Heightを指定する。

- 座標はCloseup内ボタンの親RectTransformに対する0〜1の割合。
- 原点は左下。Xは右へ、Yは上へ増える。Width / Heightは正の値。
- 例: X=0.10, Y=0.20, Width=0.30, Height=0.40なら、横10〜40%、縦20〜60%の領域。
- 右端・上端は1以下。0サイズ、負値、NaN/Infinity、親からはみ出す範囲は起動時にCatalogが拒否する。
- 背景画像のピクセル座標ではない。背景の余白・縦横比を含めGame画面上で調整する。
- 家具3箇所の範囲は従来どおりRoom内のButtonで調整する。
- この設定は画像を置く機能ではなく、ボタンとそのラベル/ハイライトの範囲を指定する。

既存6アセットの設定は変更していない。最終範囲は本番背景を受け取ってから決める。

## 仮素材での確認

1. 新ブランチを取り込み、Unityのコンパイル終了を待つ。未設定のまま起動し、DESK/BED/WINDOWの従来配置を確認する。
2. Play停止。ITEM_01だけUse Custom Hotspot=ON、Rect=(0.10,0.20,0.30,0.40)にする。ITEM_02〜06はOFF。
3. 再生してDESKを開く。ITEM_01だけ位置/範囲が変わり、ITEM_02は元の配置であることを確認。ホバー枠とクリックの範囲も確認する。
4. 取得せず部屋へ戻り、BED、WINDOW、DESKへ移動する。BED/WINDOWは元の配置、DESKではITEM_01の指定が復元されることを確認。
5. ITEM_01を取得し、ボタンが消え再取得できないことを確認。読み返し、家具完了、4個目の帰還も従来どおり確認する。
6. 必要ならPlay停止後に別のItemDefinitionも指定して独立性を確認する。Full HDと1280×720で割合が保たれることを確認。
7. 確認用のITEM_01変更はPlay停止後、Use Custom HotspotをOFFに戻す。仮の座標を本番確定値として扱わない。Gitのアセット差分を確認する。

不正値の確認はPlay停止中にWidth=0を設定して開始すると、対象ID付きのCatalogエラーになる。確認後は停止し、有効値に直して再開する。ゲーム進行が停止するため通常確認とは分ける。
