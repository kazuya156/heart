# M18: 長文表示の確認

2026-10-25追記：本文ページ分割・導入選択肢・鉛筆の質問ラベルにKENより基本確認の報告。確認用文章とITEM_01の質問ラベルは元の仮データへ復帰済み。以下は確認時の手順記録。全補助チェック/全入力/全解像度の合格を示すものではない。

ブランチ: feature/m18-long-text-check。M17の機能と確認用演出除去を含む。セットアップ再実行や手動JSON編集は不要。

## 目的

本番台詞未受領のため、現在の枠と文字サイズで表示できる長さを確認する。文字数上限の新仕様ではない。長い例がはみ出した場合は、どのサンプルで起きるかを記録して対応を判断する。文章の短縮・自動縮小・ページ分割をこの段階で勝手に導入しない。

MainSceneを確認したところ通常台詞は34px固定、選択肢は30px固定、質問ラベルは16〜24pxの自動調整。実際の改行や収まりはTMPの字形/フォントと画面配置で変わるため、コードだけで合格とはしない。

## 一時データ

| 場所 | 確認内容 |
| --- | --- |
| START直後 | 日本語60字→120字→180字（見出しと末尾目印を含む） |
| 導入選択肢A/B | 日本語50字/49字、末尾目印付き |
| 鉛筆の説明1行目 | 日本語120字 |
| 鉛筆の説明2行目 | 明示的な改行で3行 |
| 所持品の鉛筆を読み返す | 同じ説明を独立パネルで表示 |
| 鉛筆の質問ボタン | 日本語55字 |
| 鉛筆の質問台詞 | 日本語120字 |

末尾に「【末尾】」を付けた。サンプルは長さを揃えるため文の途中で区切っており、完成台詞ではない。鉛筆の表示名は変更していない。機能コードとMainSceneを変更せず、3シーケンスの表示用文章/選択肢とITEM_01のquestionLabelだけを変えている。A/Bの接続先やルールは維持。

## 手順

1. UnityのPlayを停止。Fetch originし、新ブランチへ切替。Unityのインポート終了後、Consoleを確認する。
2. GameをFull HD (1920×1080)へ。START直後の60/120/180字それぞれで1回の会話送りで全文表示する。もう1回で次のサンプルへ進む。
3. 最後の「【末尾】」まで読めるか、文字が枠外/画面外へ出ないか、話者や次へ表示と重ならないかを確認。問題のあるサンプルは画面を記録する。折り返し自体は正常。
4. 選択肢2本が互いに重ならず、末尾まで読めてクリックできるか確認する。A/Bどちらでも同じ探索へ進む。
5. 机の鉛筆を調べ、120字と明示改行3行の表示を確認。取得後、所持欄から同じ説明を読み返し、独立した枠でも末尾まで読めるか確認する。
6. ITEM_01/02/03/04を取得して追及へ。鉛筆の55字質問ボタンを末尾まで読めるか、極端な縮小がないか確認。選択して質問台詞120字の表示も確認する。
7. Gameを1280×720へ変更して同じ表示を確認。導入はPlay再開で確認できる。
8. 表示確認が終わったらPlay停止。確認用の台本とラベルはこちらで元へ戻す。確認用文章のまま配布/提出しない。

動的日本語フォントのアトラス更新がGitに出る場合がある。台本/ITEM_01の手動コミットや一括Discardはせず、変更内容を確認する。

## 検証状況

JSON解析、文字数、対象外シーケンスが元と同じことを確認。質問ID/取得判定/接続先/既存の範囲指定は維持。Unityの描画確認はKENの環境で実施する。自動レイアウト試験の成功や全文章の表示保証とは扱わない。
