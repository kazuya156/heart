# M14：取得・質問画面の日本語表示

目的：日本語フォントの準備後、詳細設計書の表示に揃える。ゲームルールは変更しない。

## Unity操作

1. Play停止、MainSceneを保存。
2. GitHub DesktopでFetch origin → `feature/m14-japanese-labels`へ切り替える。
3. Unityのコンパイル完了を待ち、MainSceneでPlay。**今回の追加メニュー操作は不要。**

M13の元OTF・SDF・既存フォント変更は5444923で保存を確認した。描画・入力の全条件まで確認済みとは扱わない。

## 変更した表示

| 場所 | 変更後 |
| --- | --- |
| 説明後の選択肢 | 取得する／取得しない |
| 質問数 | 質問 0/3 |
| コンボ | コンボ 0 |
| 動揺度 | 動揺度 0/100 |
| 未取得の質問 | ？？？ |
| 質問済みマーカー | 質問済み |
| 未取得の警告 | 必要な情報を持っていない |
| 有効質問の看守反応 | ッ！ |

未取得のLOCKは画像未受領の錠アイコン代替として残す。実アイコン受領時に差し替える。ゲームタイトルや未完成の本編台詞・アイテム名など、他の仮表示を全て翻訳した工程ではない。

## ファイルと役割

- `Assets/Scripts/Gameplay/ExplorationController.cs`：取得判断の表示ラベルだけ変更。acquire / declineの識別IDはそのまま。
- `Assets/Scripts/Gameplay/InterrogationController.cs`：質問画面の表示ラベルだけ変更。
- `Assets/Data/Scenario/scenario.json`：警告と有効反応のtextフィールドだけ変更。シーケンスID・接続・演出指示はそのまま。

## 動作確認

1. アイテム説明を読み切ると「取得する」「取得しない」が表示される。
2. 「取得しない」では所持数が増えず、もう一度調べられる。「取得する」では従来どおり枠が1つ増える。
3. 質問画面で未取得は「？？？」、押すと「必要な情報を持っていない」。質問数は消費しない。次の台詞送りで通常の心情文へ戻る。
4. 有効質問では「ッ！」が出て、表情・揺れ・赤の演出後に固定返答へ進む。
5. 使用済みの質問は灰色・選択不可。代替マーカーの「質問済み」が枠内に収まることを確認する。
6. 質問・コンボ・動揺度の日本語と数字が四角にならない。フォントはDynamicなので不足文字を実行時に補充する。
7. 01→03→05で20/50/100のTrue、01→03→02で20/50/50のBadになる従来の判定を確認する。

日本語が四角になる場合は、M13フォントの補完設定と元OTF/SDFの共有を確認する。本番素材が未完成でも、この表示確認は可能。

コードは文字列以外の構造が不変であること、C#構文・変数スコープ、台本の変更が2つのtextのみであることを静的確認した。Unityコンパイル・描画・上記操作はユーザー環境で確認する。新しい自動テストは追加していない。

確認後はPlay停止→Ctrl+S。今回の変更は既にGitへ反映済みなので、ローカルChangesが0なら追加コミット不要。UnityがフォントのAtlasなどを更新してChangesに出した場合は、内容を確認し`Save Japanese UI check`でCommit→Push originする。
