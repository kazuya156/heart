# M17: 質問待ち・未取得警告の背景とフェード

対象: feature/m17-question-prompt-cues。M16とITEM_01の初期設定保存を含む。セットアップメニュー再実行・シーン編集は不要。

## 動作

QUESTION_PROMPT / QUESTION_MISSING_INFOの1行も通常の台本の背景・効果処理を通す。指定がある場合は演出後に全文を表示する。文字送りのためにRequestAdvanceを自動実行しないので、文字表示だけで次行への入力/SEは発生しない。

特殊3台本は従来どおり空でないline1件・nextSequenceIdなし。QUESTION_VALID_REACTIONの既存の文字送りは変更しない。

演出中はPhase=Transitionと暗幕で入力を止める。全文表示までの準備中も質問ボタンを止め、表示完了後に操作を復帰する。未取得警告中は質問数を消費せず、次の会話送りで心情文へ戻す。背景指定を省略した場合は現在背景を保持するため、元の背景へ戻したい心情文には明示的にbackgroundIdを指定する。

StopPlaybackは表示完了通知を解除し、タイトルへのリセットは準備フラグを初期化する。読み返しからの復帰で演出を再実行しない。

機能コミットには本番用演出を追加しない。後続の確認用コミットだけで次の2ノードへ一時指定する。確定した物語演出ではない。KENにJSON編集は不要。確認後にこの2ノードのみ元へ戻す。

## Unity確認

1. コンパイルエラーなしを確認しPlay。ITEM_01 / 02 / 03 / 04を取得して質問画面へ進む。
2. 質問待ちの開始時に黒フェード→机の仮背景→心情文が最初から全文表示される。質問0/3のまま。
3. 未取得のITEM_05または06を押す。白フェード→ベッドの仮背景→未取得警告が全文表示される。質問0/3のまま。
4. Enterまたはクリックを1回。黒フェード→机の仮背景→心情文へ戻る。質問0/3のまま。
5. フェード中の連打やEnter/クリック重複で、質問が勝手に開始したり警告が飛んだりしない。
6. 取得済みITEM_01で質問する。通常質問は文字送りされ、有効反応と固定返答を経て質問1/3となり、黒フェードで心情文へ戻る。
7. 待機/警告の全文表示後に所持品を読み返して閉じ、元の文が戻り、背景/フェード/音が再実行されないことを確認する。
8. 3問目の結果直後は所持品操作不可、固定返答後にBadEndへ。タイトルから再開し状態初期化を確認する。

演出完了待ち・全文表示を確認するためのテストであり、最終の演出配置ではない。確認用指定を除去後、通常のBG_01の質問待ち/警告と、両エンドを再確認する。
