# 同時入力の修正（2026-10-25）

KENの実機確認で、Enterと台詞欄クリックを重ねると全文表示後すぐ次へ進む現象が発生。既存の同一フレーム抑止だけでは、キー押下とマウス解放の別フレーム入力をまとめられない。

UiInputRouterに入力操作の消費状態を追加。Enter/Space/左ボタンを重ねて押した操作は、全てを離したフレームまで再受付しない。会話・読み返し・警告解除・詳細を閉じる処理で共用する。固定秒数の待機は追加しない。

## 取り込み

Play停止。同じfeature/m15-scenario-backgroundsでFetch/Pull。シーン編集・セットアップメニュー不要。

## Unityでの再確認

1. 表示途中の長い台詞でEnter＋左クリックを重ねる。全文表示に留まり、離した後の新しい操作で次へ進む。
2. マウスを押したままEnterを押し、Enter→マウスの順と逆順の両方で離す。次行まで進まない。
3. Space＋クリック、Enter＋Spaceでも同じ。
4. 単独クリック、単独Enter/Spaceをそれぞれ押して離し、次の操作が受け付けられる。
5. 読み返し中の全文表示・ページ送り・閉じる、未取得警告の解除、導入選択後の会話が正常。
6. フェード中の連打・Alt+Tab復帰後も操作できる。
