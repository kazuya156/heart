# Heart

**記憶を探し、看守との対話から真実に迫る短編アドベンチャー**

本作は、見覚えのある部屋で目覚めた主人公が、周囲に残された手がかりを探し、鉄柵の向こうにいる看守との対話を通じて、この場所の謎に向き合う短編ゲームです。

探索で何を見つけ、看守に何を問いかけるかによって、物語の結末が変化します。

### ゲームの特徴

- **探索と情報選択**：部屋の3か所を調べ、6種類の手がかりから最大4つを入手します。
- **3回の問いかけ**：入手した手がかりを使って看守に最大3回質問します。質問の順序と内容が結末に関係します。
- **選べる発言表現**：会話中の選択肢では、主人公の言い方を自分で選べます。
- **短いプレイ体験**：セーブ・ロードを設けず、ひと続きの物語として体験する構成です。

## 制作上の工夫

**探索で得た情報が会話の選択肢につながること**、および**看守の反応と演出からプレイヤーが自分の推理の手応えを感じられること**を重視しました。

シナリオは場面ごとのJSONファイルで管理し、台詞・選択肢・立ち絵・背景・BGM・効果音の指示をUnity側で解釈する設計です。

## シナリオデータの構成

シナリオは `Assets/Data/Scenario/` 以下の5ファイルに分割しています。

| ファイル | 内容 |
| --- | --- |
| `intro.json` | 導入会話と選択肢 |
| `exploration.json` | 家具・アイテムの調査文、探索中の反応 |
| `questions.json` | 質問導入、6種類の質問、コンボ演出 |
| `true_end.json` | TrueEndの会話・演出 |
| `bad_end.json` | BadEndの会話・演出 |

各ファイルには `sequences` を収録し、`id` と `nextSequenceId` により会話を管理します。ゲームの進行、取得判定、質問回数、エンディング分岐などはUnity側のプログラムで制御します。
