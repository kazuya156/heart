# 心のオリ

**記憶を探し、謎の男との対話から真実に迫る短編アドベンチャー**

本作は、見覚えのある部屋で目覚めた主人公が、周囲に残された手がかりを探し、鉄柵の向こうにいる謎の男との対話を通じて、この場所の謎に向き合う短編ゲームです。

探索で何を見つけ、男に何を問いかけるかによって、物語の結末が変化します。

### ゲームの特徴

- **探索と情報選択**：部屋の3か所を調べ、6種類の手がかりから最大4つを入手します。
- **3回の問いかけ**：入手した手がかりを使って謎の男に最大3回質問します。質問の順序と内容が結末に関係します。
- **選べる発言表現**：会話中の選択肢では、主人公の話す内容を自分で選べます。
- **短いプレイ体験**：セーブ・ロードを設けず、ひと続きの物語として体験する構成です。
